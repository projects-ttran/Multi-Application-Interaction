# Multi-Application-Interaction

This is my most recent project that is constantly being updated due to unfortunate bugs I keep finding.  It works, but can be more efficient with system load and timing.
This script runs 38 applications in 19 pairs at once on a fixed clock cycle, detecting errors and bad applications, forcing them to restart.
The file itself is AutoHotKeys Version 2 but it incorporates Python from an additional program that injects and changes the main program in pairs, and by the far the greatest project I've spent months working on.

Note: This code is heavily altered but the structure can be applied to any systematic game action repetition, and I will add notes within the actual script.
There are also at least 100 versions of this code but I will only upload the most recent edit to show the structure.  I believe 10ish more edits will finalize this project.
